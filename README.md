# To-Do List Web Application

A simple, responsive To-Do List built with HTML, CSS, and vanilla JavaScript.

## Features

- Add tasks
- Mark tasks as completed or pending
- Delete individual tasks
- Clear all tasks after confirmation
- View total, pending, and completed task counts
- Save tasks in browser Local Storage
- Responsive layout for desktop and mobile

## Run locally

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the Live Server extension.

No build tools or external dependencies are required.

## Files

- `index.html` — application structure
- `style.css` — layout and styling
- `script.js` — task actions and Local Storage
